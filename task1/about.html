About me

I build with people in mind.

My goal is to make the web faster, simpler, and more inclusive.

My approach

I believe accessibility should be part of the development process from the beginning rather than something added at the end of a project.

I use semantic HTML, progressive enhancement, responsive CSS, and carefully considered JavaScript to create interfaces that work across devices and input methods.

  • WCAG Accessibility
  • Web Performance
  • SEO Fundamentals
  • Git and Version Control

What matters to me

Accessibility

Interfaces should be usable by people with different abilities, devices, and interaction methods.

Performance

A beautiful website should also be fast and efficient.

Simplicity

Clear content and purposeful design create better user experiences.
